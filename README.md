# RV Survival
Unreal Engine 5.8 C++ / Windows PC / cooperative listen server.

Gates 1, 2 and 3 are accepted after live Unreal validation. Gate 3 establishes the purchased Class C RV, native networked moving-interior walking and six fixed workstation interaction placeholders. Future survival systems remain unimplemented. Work stops after Gate 3.

- [Gate 1 validation](Docs/GATE_1_VALIDATION.md)
- [Gate 2 validation](Docs/GATE_2_VALIDATION.md)
- [Gate 3 architecture, results and limits](Docs/GATE_3_VALIDATION.md)

Production art lives in `/Game/RV`; project configuration is `/Game/Vehicles/Gate3/BP_ClassCMotorhome`. Original vendor packages and prototype fallbacks are preserved. Review map: `/Game/Maps/Gate3MovingInteriorTest`. Startup/default map remains Gate1Test.
