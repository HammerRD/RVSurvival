# Gate 2 evidence and rerun guide

These results were recorded from live Unreal Engine 5.8.3 PIE on 2026-10-05. JSON assertions are the acceptance evidence; build.log records the final Development Editor / Win64 build. fixture.json records loaded content and Chaos configuration. Development failures were fixed and rerun; the validation document explains the gameplay fixes.

The prototype uses Epic's installed engine vehicle-template assets under Content/Vehicles/OffroadCar, plus the referenced SportsCar base material and three textures. BP_PrototypeMotorhome configures the rig and four wheel bones. No purchased model is required. The primitive shell and vehicle rig are replaceable independently of seat/network code.

To rerun on this workstation, copy the scripts in this folder to Saved/Gate2Validation (the paths inside them target D:/GitHub/RVSurvival/RVSurvival). Keep the accepted Gate 1 regression scripts in Saved/Gate1Validation; copies are included here in the gate1_scripts folder. Open /Game/Maps/Gate2VehicleTest, set Play As Listen Server, stop PIE, and execute `py "D:/GitHub/RVSurvival/RVSurvival/Saved/Gate2Validation/reopen.py"` in the editor console. It starts the 24-check same-process suite. After GATE2_MULTI_DONE, execute race.py for simultaneous driver claims and a held E across possession. Stop PIE, then execute final_suite.py for separate-process baseline, server outgoing 100 ms latency/2% loss, passenger disconnect and Gate 1 regression. final_suite.py stops at a failed assertion and preserves diagnostics; it does not accept the gate automatically.

The suite uses live Enhanced Input key injection. Fixture teleports arrange characters at doors; resetting the vehicle separates driving phases. Position/velocity comparisons measure native server Chaos movement and replicated proxies. Actor names differ between processes; occupancy assertions compare mapped survivor references or seat booleans appropriately. Tests cover two players, not five-player sessions or a packaged/dedicated-server build.

An initial post-test cleanup map reload from a Slate Python callback crashed PythonScriptPlugin after all gameplay assertions had passed. cleanup_crash.log preserves it. The corrected final_suite.py unregisters before cleanup and does not reload the editor map from that callback. After the suite finishes, open Gate2VehicleTest normally or execute restore_editor.py from the editor console. verify_cleanup.py reruns the corrected cleanup function and sets a useful prototype viewport. Recovery and corrected cleanup passed; the underlying editor/Python crash is not fixed in engine code.
