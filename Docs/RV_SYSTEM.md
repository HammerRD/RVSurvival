# RV system plan
No vehicles before Gate 1 acceptance. Gate 2 isolates Chaos behind ARVVehicleBase and composes ARVMotorhome with authoritative seats. Gate 3 prototypes passenger movement behind a replaceable reference-frame boundary.

Gate 3 is a hard technical stop: two clients, highway-speed driving, front-to-rear passenger walking, stable physics and visuals. No teleportation into a separate static interior. Do not expand inventory/combat/world content while this remains unacceptable.

Future systems separate fuel, individual mechanical conditions, automotive power and house power; no generic RV health. Cooling dependencies and empty-fuel propulsion blocking belong to later gates.
