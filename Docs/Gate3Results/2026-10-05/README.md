# Gate 3 evidence and rerun notes

These are real local Unreal Engine 5.8.3 PIE results, not unit tests or compile-only evidence. JSON `results` entries retain booleans and measured details. `samples` contain approximately 20 Hz passenger/vehicle telemetry. Paired files compare independently collected server/client samples; their PIDs prove separate processes. Shared-process observer assertions compare independent replicated characters in the two PIE worlds.

Test inputs use Unreal's `Input.+key`/`Input.-key` Enhanced Input path, normal possession and normal walking sweeps. Initial fixture character placement happens before movement. Standing/walking passengers are never teleported to force a test result. Stations are aimed at once per hold; they are not followed by a transform loop. Driving is real Chaos acceleration/braking/steering, not scripted vehicle movement.

Network emulation is 100 ms outgoing-server packet latency and 2% outgoing-server packet loss. It is not claimed as 100 ms latency applied independently in every direction. Finite successful samples are not exhaustive network-fault guarantees.

Rerun scripts will be archived in `Scripts`. They expect this local project path and use project-scoped `Saved/Gate3Validation`/`Saved/Gate2Validation` jobs. Load maps only from normal Unreal Python startup/console execution, not from a Slate post-tick callback (the latter previously caused an editor GC crash). Stop PIE before map or asset edits. Keep background CPU throttling off and cap the test at 60 FPS; restore ordinary settings afterward.

The original `/Game/RV` vendor packages are verified with SHA256, and runtime art has no collision. `materials_configured.json` verifies all 54 project-side visual parts match the vendor Blueprint materials. Translucent glass uses a project component Nanite override, without modifying the original mesh. `lane_config.json` records the wider Gate 3-only driving lane and two Player Starts.

See `../../GATE_3_VALIDATION.md` for the final acceptance decision, measured limits and outstanding issues. Discarded trial failures are discussed there and are not included as passing acceptance evidence.
